# DesignStudio

**Design, motion, media and 3D — one studio, fully offline.**

DesignStudio is a professional design tool that runs entirely in your web browser. Nothing is
installed and nothing is uploaded: your files stay on your computer.

## Start

1. Save **`DesignStudio-<version>.html`** anywhere (for example `Documents\DesignStudio`). It is the whole app in one file.
2. Double-click it. It opens in your default browser.
3. Pick **Design**, **Animate**, **Media** or **3D** on the welcome screen — a short tour shows the essentials.

Recommended browsers: Google Chrome or Microsoft Edge (latest). Firefox and Safari are supported;
video export is fastest in Chrome / Edge.

## What's inside

| | |
|---|---|
| **Design** | Frames, vector shapes, text, components & variants, auto layout, design system (variables, modes, styles), prototyping, developer handoff |
| **Animate** | Timeline, easing curves, state machines, inputs and triggers |
| **Media** | GIF / video / image editing, compression, conversion (GIF, APNG, WebP, MP4, WebM), rulers & guides |
| **3D** | Primitives, models (GLB / OBJ / STL), materials, lights, dope-sheet timeline, guides, interactive 3D export |
| **Links** | Use 3D scenes and Media frames in Design and Design layers in 3D — they stay in sync |
| **AI** | Connect your own AI provider or AI apps (Claude, Cursor, VS Code…) through the local bridge (AI panel › AI apps › Save bridge files) |
| **Plugins** | Write, test and install your own sandboxed plugins (Plugins › Plugin Studio), or import `.dsplugin` files |

## Your work

- DesignStudio autosaves in this browser. Use **File › Save** to keep a portable `.designstudio.json` file.
- Exports: PNG, SVG, code (HTML / CSS / Tailwind / React / Vue / Svelte / SwiftUI / Flutter), design
  tokens, Lottie, CSS animation, animated SVG, video, GIF and interactive HTML.
