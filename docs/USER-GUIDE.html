Getting started

  1. Open DesignStudio.html in Chrome or Edge (Firefox and Safari work too).
  2. On the welcome screen choose Design, Animate, Media or 3D, or start from a Desktop, Mobile or Tablet frame.
  3. A six-step tour points out the essentials. Run it again any time from About › Take the tour (click the logo).
Everything runs in your browser. Your work autosaves in this browser — use File › Save for a portable .designstudio.json file you can back up or share.

The interface

AreaWhat it does

LeftTools (Design), Media tools, or the 3D add panel and scene outliner.
CentreCanvas, media stage or 3D viewport — with rulers and guides in all three.
RightProperties of the selection: Design, Prototype and Inspect tabs; Media tool options; 3D inspector.
Status barSelection, zoom, grid / snap state and the version (click it for diagnostics).

Every dialog can be dragged by its title bar; double-click the title to re-centre it. Drag the inner edge of the Layers or Properties panel to resize it, and press Ctrl+\ (or Panels in the status bar) to hide both side panels for a full-width canvas.

Design

Frames and shapes

Press F and pick a size (phone, tablet, desktop, social…) or drag on the canvas. Draw with R rectangle, O ellipse, L line, Shift+L arrow, P pen, T text. Drop images or SVG files straight onto the canvas.

Lines and arrows

Drag an end point to move it; drag the middle handle to curve the line. Arrow presets and end caps are in the Design panel.

Layout

Auto layout (Shift+A), constraints, layout grids, alignment and distribution are in the Design panel. Drag from a ruler to add a guide; drag it back to remove it.

Components and design system

Create a component with Ctrl+Alt+K. View › Design System manages variables and modes (light / dark), colour, text and effect styles, components, health checks and token import / export. Start from a preset system if you like.

Animate & prototype

Switch to Animate in the top bar — Auto-key turns on, so moving, resizing or recolouring the selected layer at a new time records a keyframe (an empty timeline shows the steps); edit easing in the timeline. State machines, inputs and triggers make interactive animation without code (Prototype tab › Triggers).

For click-through prototypes, open the Prototype tab, select a layer and drag its ⊕ handle onto a frame. Press Play to try it.

Media

Open a GIF, video or images (or drop them). Tools on the left: resize, crop, rotate, trim, speed, reverse, frame delays, text, overlay, censor / blur, effects, transparency, GIF and video compression, and export to GIF, APNG, WebP, MP4, WebM, frames (ZIP) or sprite sheet.

Animate mode focuses on frame tools and opens the frame strip. Rulers and guides measure source pixels; Grid shows a pixel grid; Snap makes crops snap to guides and edges.

3D

Add primitives and lights from the left panel, import GLB / glTF (embedded) / OBJ / STL, or Extrude from Design. Move / rotate / scale with W E R; focus with F.

Timeline

Switch to Animate (auto-key on) and move objects, or press K to key the selection. In the dope sheet select keys (click, Shift, drag a box), drag them in time, copy / paste (Ctrl+C/V), change easing or draw a custom curve. ＋ Track animates any property, including shape keys (geometry size) and model morph targets. Loop, ping-pong, speed and play range (I / O) are in the bar.

Guides

Drag from a viewport ruler to drop a guide plane; objects snap to guides while moving. Guides in the 3D toolbar adds guides through the selection and edits them.

Export gives PNG, GLB and an interactive 3D web page that keeps animations and triggers.

Links between tabs

Click 🔗 Links in the top bar (or To Design in 3D, Use in… in Media):

  • 3D view or object → Design — an image layer that re-renders after every 3D edit. Select it to orbit, rotate, recolour and re-pose the object right in the Design panel, or double-click it to adjust on the canvas.
  • Media frame → Design or 3D — updates after every Media edit.
  • Design layer → 3D — an image plane, e.g. a UI screen on a 3D card; updates with your design.

Unlink keeps the last image as a normal layer.

Comments & versions

Press C (or the comment button) in any tab and click to pin a comment; in 3D pins stick to objects. File › Save Version… keeps named versions; File › Share Package exports a ZIP with the project, interactive HTML, previews and comments.

AI & AI apps

✦ AI opens AI Studio: paste your own API key or a local model address, then ask for screens, edits, tokens, critique or code. Keys stay in this browser.

AI Studio opens as its own column next to Properties, so you can keep editing what it makes; drag its left edge to resize it.

AI apps (Claude Desktop, Claude Code, Cursor, VS Code…) can read and edit the open file through the local bridge in mcp/ (needs Node.js 18+; see mcp/README.md). The bridge only listens on this computer and pairs with your DesignStudio tab.

Touch & pen

One finger uses the current tool, two fingers pinch to zoom and pan, long-press opens the context menu. A pen works like a mouse with palm rejection; its barrel button opens the context menu.

Privacy & security

  • No account, no upload, no tracking: DesignStudio makes no network requests of its own.
  • Files you open are checked: hostile project files, oversized "bomb" images, SVGs with scripts and 3D models that point to the internet are neutralised or refused with a message.
  • A strict Content-Security-Policy stops any injected or remote script from running.
  • AI providers you connect are contacted only when you use AI, over HTTPS (or on this computer).

Developer handover

The Handover tab (next to 3D, Ctrl+Alt+4) is where developers pick up finished designs.

  1. Commit: in Design, select the finished screens. Ctrl+A selects everything; selecting a layer inside a frame counts as its whole screen. A Commit to Handover button appears at the bottom of the canvas (or press Ctrl+Alt+Enter). Add a title and a note, then commit. DesignStudio saves a frozen, numbered version (v1, v2…) and opens it in Handover. Later edits in Design don't change it.
  2. Inspect: click any layer on the screen to see its specs: size, position, spacing to its screen and parent, colours, type and effects. It also offers code (CSS, React, SwiftUI, Jetpack Compose, Flutter) and assets (SVG, or PNG at 1×, 2× and 3×). Select one layer and hover another to measure the distance between them. Esc clears the selection.
  3. Track: each version has a status: Ready for development, In development, Changes requested or Done. A version shows what changed since the previous version of the same screens, with changed and added layers highlighted on the screen.
  4. Hand off: Download package makes a .zip with a README, spec.json (every layer, relative to its screen, with notes), tokens.json, screen previews, HTML + CSS and React code, and the original images. Designers can leave a Note for developers on any layer.

Handover versions are saved in the project file, so they travel with it.

Plugins

Plugins add your own tools. Open Plugins › Plugin Studio… to write, test and install them; installed plugins appear in the Plugins menu.

  1. Start from a template (Grid of shapes, Rename layers, Recolour, Distribute, Confetti, Blank), or type what you want in the AI box and press Write with AI. AI needs a connection in the AI panel.
  2. Run it (Ctrl+Enter). Output and errors appear under the code. Each run is one undo step.
  3. Save (Ctrl+S) and tick In Plugins menu. Export… makes a .dsplugin file to share; Plugins › Import Plugin… installs one after showing what it asks for.

Plugins run in a sandbox with no access to the page, your files or the internet. They can only use what you allow: read layers, write (create, change, delete), ui (ask you with a small form) and network (https, only the domains listed). A run is stopped after 10 seconds of work or 5,000 changes. Only install plugins from people you trust.

CallDoes
ds.selection() · ds.layers() · ds.get(id)Read layers (x, y, width, height, fills, text…)
ds.create(type, props) · ds.update(id, props)Make or change a layer: rect, ellipse, line, arrow, polygon, star, text, frame
ds.remove(ids) · ds.select(ids)Delete or select layers
ds.ask(title, fields)A form: number, text, colour, select or checkbox. Returns the values, or null when cancelled
ds.viewport() · ds.notify(text) · ds.storage.get/set · ds.fetch(url)View centre and size · a message · saved plugin settings · a web request (network)

GitHub repos

Bring icons, images, plugins and design tokens in from any GitHub repository.

  • File › Import from GitHub…: type owner/repo or paste a github.com link (a folder link opens that folder). Tick the SVGs, images or .dsplugin files you want, then press Import. SVGs become editable layers.
  • With AI: ask in the AI panel, for example “import the arrow icons from owner/repo” or “turn the tokens in owner/repo into variables”. The AI lists and reads the repo, and nothing is imported until you confirm.
  • Private repos: open “Add a token” and paste a fine-grained token from github.com › Settings › Developer settings with Contents: Read-only. It is kept for this session only unless you tick Remember on this device, and it is never written to logs. Without a token, GitHub allows 60 requests an hour.

DesignStudio only reads from GitHub and never runs code from a repo. Plugins from a repo go through the normal permission prompt and run in the plugin sandbox.

Settings

Open Edit › Settings… or press Ctrl+,. Changes apply straight away and are saved in this browser. Reset to defaults undoes them.

  • Undo steps (10–100, default 100): how far Ctrl+Z goes back. Steps share the unchanged parts of your document, so 100 steps of a large file usually take only a few MB.
  • Undo memory limit (200 MB–1.5 GB): a safety net for very large documents. If history would use more, the oldest steps are dropped, but at least 10 are always kept.
  • 3D performance: Auto (recommended) lowers resolution while you orbit, drag or play and returns to full sharpness when you stop. On very heavy scenes it also simplifies shadows. Quality, Balanced and Performance are fixed presets. Custom lets you set shadows, shadow resolution, sharpness on high-DPI screens and resolution while moving.

Shadows are cached in every mode, so moving the camera doesn't redraw them. Exports always render at full quality. The dialog shows live numbers for undo memory and the 3D view.

Diagnostics & health

The dot at the bottom right of the status bar shows how the app is doing: green means healthy, amber means check, and red means there's an issue. Click it, choose Help › Diagnostics…, or press Ctrl+Alt+D. Everything is measured inside your browser and is never sent anywhere.

TabWhat it shows
OverviewMemory (JavaScript heap and undo history size) · Main thread (CPU), the share of the last 10 s the app was blocked by long tasks (browsers don't expose CPU %) · Responsiveness (event-loop delay) · Frame rate · Storage · API response time · Errors, each with a short history.
LogsErrors, warnings and app events. Filter, search, copy or export them as .txt. Tick Previous session to read the log from before a reload or crash. API keys are hidden automatically.
NetworkResponse time per service (AI providers, the MCP bridge, local models): p50, p95, max and errors, plus the latest calls. Only the address and timing are kept, never query strings, headers or content.
StorageBrowser storage is the app's database. Test the connection, see the quota used, ask the browser to keep your data, and check autosave timings and failures.
BenchmarkA 3-second render test on a hidden canvas that shows how much this device can draw. Your document isn't touched.

If something turns red (memory, main thread or a slow or failing service), you get one short tip, repeated at most every 5 minutes. Export report saves everything as a .json file you can attach to a bug report. On very large documents, undo history is capped at about 150 MB (always at least 20 steps) so memory stays under control.

Troubleshooting

ProblemTry
3D tab says it cannot startEnable hardware acceleration in the browser settings; update the graphics driver.
Video export is slow or missingUse Chrome or Edge (hardware video encoding).
"File is too large" / "megapixels" messageThe file exceeds a safety limit — resize or compress it first.
Work missing after clearing browser dataAutosave lives in the browser — keep a saved .designstudio.json as a backup.
App feels slow or the dot is amber/redOpen Diagnostics (Ctrl+Alt+D): the red tile says what's wrong. For memory, save and reload the tab. For the main thread, close heavy effects or split large pages. Export the report if you need help.
AI app can't see the fileStart the bridge in mcp/, then open ✦ AI › AI apps; only one DesignStudio tab can be paired at a time.

When reporting a problem, click the logo › Copy diagnostics and include it.
